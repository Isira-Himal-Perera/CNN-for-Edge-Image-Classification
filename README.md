# EN3150 - Assignment 03: Resource-Constrained CNN for Edge Image Classification

The project focuses on designing, training, and evaluating lightweight convolutional neural networks (CNNs) optimized for resource-constrained edge and embedded devices.

---

## 📂 Repository Structure

- `data/`         - Dataset loading, preprocessing, and 64x64 downscaling scripts (70/15/15 split).
- `notebooks/`    - Jupyter notebooks used for exploratory data analysis and visual verification.
- `report/`       - Final report documents and source files.
